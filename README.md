# Anthony Dong's Portfolio Website

## Live Website
[View the live portfolio website](https://anthonyzhdong.netlify.app/)

## Project Overview
This is a personal portfolio website built using React, designed to showcase my skills, projects, education, work experience, and more. The website provides a comprehensive view of my professional background and achievements.

## Technologies Used
- **React**: Front-end JavaScript library for building the user interface
- **React Router**: For navigation between different sections of the portfolio
- **CSS**: Custom styling for all components
- **Netlify**: For hosting and deployment

## Features
- **Responsive Design**: Fully responsive layout that works on all device sizes
- **Interactive Navigation**: Easy navigation between different sections
- **Project Showcase**: Display of my GitHub repositories with descriptions and technologies used
- **Work Experience Timeline**: Visual representation of my professional journey
- **Education History**: Details about my academic background
- **About Me Section**: Personal information, skills, interests, and goals
- **Contact Information**: Different ways to connect with me
- **CV Download**: Option to download my resume

## Project Structure
The project is organized into several key components:

- **Home**: Landing page with a brief introduction and navigation to other sections
- **About Me**: Detailed information about my background, skills, and interests
- **Projects**: Showcase of my coding projects with GitHub links
- **CV**: View and download my resume
- **Work Experience**: Timeline of my professional experience
- **Education**: Overview of my academic qualifications
- **Contact**: Various ways to reach me

## Running the Project Locally

### Prerequisites
- Node.js (v14.0.0 or higher)
- npm (v6.0.0 or higher)

### Installation
1. Clone the repository
   ```
   git clone https://github.com/anthonyzhdong/portfolio.git
   ```

2. Navigate to the project directory
   ```
   cd adport
   ```

3. Install dependencies
   ```
   npm install
   ```

4. Start the development server
   ```
   npm start
   ```

5. Open your browser and visit `http://localhost:3000`

## Deployment
The website is deployed using Netlify. Any changes pushed to the main branch are automatically deployed.

### Manual Deployment
1. Build the project
   ```
   npm run build
   ```

2. Deploy the contents of the `build` folder to your hosting provider

## Customization
This portfolio is designed to be easily customizable:

- Update personal information in the respective component files
- Replace images in the public folder
- Modify the CSS files to change the styling and colors
- Add or remove sections as needed
